# CSHARP-practice
این repository درباره حل تمرینات زبان برنامه نویسی C# است 

## تمرین‌ها
- Exercise01: گرفتن یک عدد از کاربر و چاپ زوج یا فرد بودن آن
- Exercise02: گرفتن عدد از کاربر و چاپ مجموع اعداد از یک تا عدد کاربر
- Exercise03: بررسی اعداد بین ۱ تا ۲۰ و چاپ اعداد زوج 
- Exercise04: گرفتن یک عدد از کاربر و بررسی اعداد بین یک تا عدد  کاربر و چاپ تعداد اعداد زوج و حاصل جمع آن ها
